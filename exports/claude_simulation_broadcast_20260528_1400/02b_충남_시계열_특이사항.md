## 모델 식 (참고)

```
weight_i = exp(-(today - 조사중간일) / 7 * ln(2))    # half-life 7일
margin_가중평균 = sum(weight_i * margin_i) / sum(weight_i)
margin_SD = sqrt(시계열 가중분산 + 측정오차분산)
            = sqrt(27.70 + 25.00) = 7.26 %p
```
