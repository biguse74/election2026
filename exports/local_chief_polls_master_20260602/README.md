# 전국 기초단체장 여론조사 수집 — 마스터 체크리스트

## 파일
- `기초단체장_226_마스터체크리스트.csv` — 전국 227곳 전체. 8회 결과·접전도·9회 사전·본선 구도 + 폴 채울 빈칸 6개.
- `우선검색_대상.md` — 폴이 있을 확률 높은 89곳(접전·이변지). **여기부터 검색.**

## 워크플로우
1. `우선검색_대상.md`의 시도별 목록을 보고, 아래 프롬프트로 **시도 1개씩** 퍼플렉시티 검색.
2. 받은 폴을 마스터 CSV의 `[폴]` 6개 칸에 채움.
3. 채운 걸 클로드(이 세션)에 주면 **여심위·기사원문 대조**로 환각·날짜오류·깜깜이위반 필터링.

## ⚠️ 전북에서 얻은 교훈 (중요)
퍼플렉시티가 찾는 건 대부분 **3월 "민주 경선 적합도" 폴**이다. 본선(민주 vs 무소속·혁신·국힘)과 다르다.
→ 그러니 폴은 **"본선 예측"이 아니라 "적합도 1위 ↔ 실제 공천자 대조 = 공천에서 누가 잘렸나"** 결산용으로 본다.
→ 본선 구도는 이 CSV의 `본선구도` 칸(선관위 공식)이 정답.

## 퍼플렉시티 프롬프트 (시도명·시군구 목록만 갈아끼움)
```
당신은 한국 선거 여론조사 리서처다. 제9회 지방선거(2026-06-03) [시도명]의 다음 시군구 기초단체장 선거에 대해, 언론에 공표된 여론조사를 찾아라: [우선검색_대상.md의 해당 시도 시군구 나열].

엄격한 규칙:
- 중앙선거여론조사심의위(nesdc.go.kr) 등록·공표 여론조사만. 깜깜이(~2026-05-27)까지 공표분만.
- 각 조사마다: 시군구/조사기관/의뢰자/조사일/표본·응답률/후보별 지지율(이름·정당)/1·2위 격차/보도매체·기사URL/여심위 등록번호.
- 기사 URL이나 등록번호로 확인 안 되는 수치는 "미확인". 절대 지지율을 추정·창작하지 마라.
- 폴이 없는 시군구는 "공표 폴 없음"으로 명시. 빈칸을 추정으로 메우지 마라.
- "경선 적합도 조사"인지 "본선 구도 조사"인지 반드시 구분해 표기하라.
출력: 시군구별 markdown 표.
```
