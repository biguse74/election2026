## 빠른 사용법

Claude에 넣을 때는 먼저 `00_CLAUDE_PROMPT.md`와 `01_STORY_BRIEF.md`를 붙이고, 필요한 CSV를 추가로 첨부하면 됩니다.

가장 추천하는 기사축은 세 가지입니다.

1. 최근 5년 체납 이력 1,072명: 현 체납 66명만 보면 놓치는 검증 포인트
2. 전과 공개 후보 2,627명: 공직 검증 유형 1,293명, 음주·위험운전 949명
3. 정당별·직책별 후보 검증: 체납 이력 후보 중 국민의힘 451명, 구시군의회의원 644명

## 파일 구성

- `00_CLAUDE_MASTER_INSTRUCTIONS.md`: Claude에 먼저 넣을 전체 작업 지침
- `00_CLAUDE_PROMPT.md`: 짧은 기사 작성 요청 프롬프트
- `01_STORY_BRIEF.md`: 기사 핵심 요약, 제목 후보, 리드 후보
- `02_BROADCAST_RUNDOWN_60MIN.md`: 1시간 방송 구성안
- `03_DATA_NOTES_AND_CAVEATS.md`: 데이터 기준과 표현 주의사항
- `data/key_stats.json`: 핵심 숫자 JSON
- `data/story_ideas.json`: 기사 아이템 후보 JSON
- `data/*.csv`: 기사 작성·검증용 CSV

## 공개 표현 원칙

- “선관위 후보자 공개정보 기준”이라고 쓰는 편이 안전합니다.
- 전과는 죄명 표현을 넓은 범죄 유형으로 묶은 자료입니다. 후보별 인용·보도 시 선관위 후보자 상세 페이지 원문을 함께 확인하세요.
- 최근 5년 체납은 과거 이력, 현 체납은 현재 남아 있는 체납액입니다. 두 숫자는 서로 다른 의미입니다.
- 정당별 수치는 “해당 항목 후보 안에서의 비중”과 “정당 전체 후보 중 비율”을 구분해서 쓰세요.
