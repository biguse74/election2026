# 전북 사전투표 데이터 브리프 — 전북지사 선거 분석 보강용

> 뉴탐사 자체 집계. **9회(2026.6.3) vs 8회(2022.6.1) 시군별 사전투표율** + 전북지사 선거 맥락.
> 동봉 파일: `jeonbuk_sigungu_9th_vs_8th.csv` (15개 시군구, 증감폭 순)
> 작성 기준일: 2026-05-31 / 출처: 중앙선거관리위원회 사전투표 통계

---

## 1. 한 줄 사실
- **전북 사전투표율: 8회 24.41% → 9회 35.05% (+10.64%p), 전국 시도 2위(1위 전남 38.95%).**
- 전북 15개 시군 **전부 상승**. 도시(군산·전주)가 평균(+9.04%p)보다 더 크게 튐.

## 2. 전북지사 선거 구도 (뉴탐사 2026.5.12 보도 기준)
- **김관영(현 지사, 무소속) 43.2% vs 이원택(더불어민주당) 39.7%** — 무소속이 앞섬, 뉴탐사 시뮬 당선확률 79%.
- **제명 경위**: 3/31 "청년 대리운전비 68만원" 명목 제보 → 4/1 약 12시간 만에 민주당 제명. (김관영 측: "부담 느껴 회수 지시") — *별도 팩트체크 대상, 데이터 분석과 분리.*
- 무소속 선언(5/7) 후 1주일 만에 +6.6%p 급등.
- **민주당 윤리감찰 "공정하지 않다" 44.1% > "공정하다" 34.2%** (공천 불신 여론 실증).
- 권역: 5권역 중 **4곳 김관영 우세**(전주·서부·정읍고창·동부완주), **익산만 이원택**(-13.4%p). 서부(군산·김제·부안) 김관영 +9.7%p.

## 3. 핵심 정합성 — 데이터 ↔ 선거 구도
- **군산 사전투표 +12.53%p (전북 '시' 단위 상승 1위)** ↔ 군산은 김관영 연고(국회의원 3선)·서부권 김관영 우세.
- **익산 +9.45%p**(민주 이원택 유일 우세지)도 상승 — 즉 **친이원택(익산)·친김관영(군산)이 둘 다 사전투표 급등**.

## 4. 분석에 꼭 반영할 '방향 모호성' (가장 중요)
사전투표율↑은 **두 정반대 동력이 같은 숫자로** 나타난다:
- (A) 여당(민주) 힘 실어주기 결집 → 이원택 유리
- (B) 정청래식 공천 불신·심판 동원 → 무소속 김관영 유리

**사전투표율 숫자만으로는 A/B를 못 가린다.** 익산↑(A)과 군산↑(B)이 공존하는 게 그 증거.
→ "사전투표율 전국 2위 전북, 그런데 도지사 1위는 무소속"이 성립할 수 있음. **"사전투표율↑=여당 유리"의 전국 최강 반례 후보.**

## 5. 4겹 해석 모델 (전북에 작용하는 힘)
1. **정권 사이클**: 8회=윤석열 집권 첫해(보수 기세·진보 위축), 9회=이재명 정부 2년차(여당 결집) → 호남 4년 전 기저가 낮아 상승폭 과장 측면.
2. **진보 사전선호 / 보수 사전불신** — 일반 경향.
3. **사전투표 보편화** — 전국 +2.9%p 기저상승.
4. **전북 고유: 공천 불신·무소속 반란** — 여론조사·시뮬로 뒷받침(가설→정황).

## 6. 이 데이터로 추가 분석해볼 것 (프로젝트 요청사항)
1. 시군별 사전투표 상승폭 ↔ 김관영/이원택 권역 우세도의 상관 — **B(반발 동원) 가설을 지지하는 공간 패턴이 있나?**
2. 군산(연고)·전주(도심)의 초과 상승이 단순 도시화 효과인지, 김관영 결집 신호인지 구분 가능한가?
3. 익산(이원택 우세)의 상승은 A로, 군산은 B로 읽는 게 타당한지 — 반례·교란요인은?
4. 6/3 개표에서 A/B를 가릴 검증 지표 제안(무소속 득표율, 권역별 격차 등).

## 7. 면책 (기사화 시 필수)
- 사전투표율 변화는 **동원 시점·방식의 차이**이지 득표·당락의 직접 예측이 아니다(2022 대선: 사전 36.9% 역대최고였으나 보수 승리).
- 제명 경위(대리운전비·CCTV 등)는 김관영·정청래·이원택 측 입장 균형 + 물증으로 **별도 팩트체크**.
- 권역 우세도는 5/9~10 여론조사 스냅샷 — 사전투표(5/29~30)·본투표(6/3)와 시점 차이.
